### Description (Max 4,000 characters)
```text
TagSpeak is an accessibility-first utility designed for blind and low-vision users to create, read, and edit spoken labels on inexpensive, off-the-shelf NFC stickers (such as NTAG213, NTAG215, and NTAG216).

Every label is stored directly on the physical NFC sticker using a standardized NDEF text record. TagSpeak requires zero accounts, zero cloud subscriptions, zero internet access, and no proprietary tag lock-in. Stickers written with TagSpeak on iOS can be read by TagSpeak on Android and vice versa.

KEY FEATURES

1. Instant VoiceOver-First Reading
• Read stickers aloud immediately using high-quality speech synthesis or VoiceOver.
• Built-in integration with the iPhone Action Button, Back Tap, and Siri Shortcuts ("Read TagSpeak Sticker") so you can scan items in a split second without navigating menus.
• Optional "Automatically start scanning on app launch" setting for instant one-touch reading.

2. Create, Inspect, and Relabel Stickers
• Write Label: Type or dictate a custom label, monitor live UTF-8 byte capacity, and hold your iPhone near an NFC sticker to write it.
• Scan Existing Sticker to Edit: Hold a sticker to your phone to load its current text directly into the editor, tweak it, and save it back.
• Inspect Sticker: Review spoken label text, NDEF byte capacity, and tag writability.
• Overwrite Protection: TagSpeak alerts you before replacing an existing label so you never accidentally overwrite an important item. (Can be toggled off in Settings for quick batch relabeling).

3. Built Exclusively for Assistive Technology
• Designed ground-up for VoiceOver, braille displays, and keyboard navigation with standard iOS semantic controls.
• Independent speech rate controls (0.75x to 2.0x) and a live audio test button.
• High contrast, clean visual interface with dynamic type support.

4. 100% Offline & Private
• Operates completely offline with zero internet access, zero accounts, and zero analytics. Your labels stay on your physical stickers and nowhere else.
```

## 4. App Review Notes (For Apple Review Team)
```text
TagSpeak is an assistive utility that enables blind and low-vision users to label household items (canned goods, spices, medications, cables) using inexpensive standard NFC stickers.

Testing Instructions:
1. No login, account, or internet connection is required.
2. To test reading, hold an NFC sticker to the top edge of the iPhone and tap "Read Sticker Aloud" (or use the Action Button/Shortcuts).
3. To test writing, enter any text into the "Spoken Label" text field, tap "Write Label to Sticker", and touch an NFC sticker.
4. VoiceOver support is fully native throughout all screens and dialogs.
```
